子集型DP

发表于 2019-07-07- 更新于 2026-09-20
8.7k- 41m
算法竞赛

这次来聊一聊DP中的子集型DP。

一.概述

DP，即动态规划。最优化问题是信息学竞赛的一大类题目， 动态规划是解决这类问题的有力武器， 但很多人在尝试理解并运用它时遇到极大的困难！当你学习了足够多的动态规划例题的时候，你会觉得它跟变魔术一样。

二.实质

动态规划实质就是记忆化搜索，是一种高效地实现回溯算法的方法，它的核心是用一个状态记忆表来记住所有中间状态的结果。因此我们要运用动态规划，首先需要发现朴素的回溯算法递归地一而再、再而三地计算一些相同的子问题，接下来需要把答案放在记忆表中而不重复计算。动态规划可以采用记忆化搜索，但记忆化搜索有其缺点，比如要用递归，不能优化空间。所以填表法作为动态规划实现的一种优化方法而广泛使用。

三.例题

1.背包问题

(1).01背包

有 NNN 种物品，每种物品只有 111 个。第 iii 种物品的体积为 v[i]v[i]v[i]，价值为 p[i]p[i]p[i]。选一些物品装入一个容量为 CCC 的背包，使得背包内物品在总体积不超过 CCC 的前提下价值尽量大。

分析：

[1].不正确的贪心

采用部分背包问题的贪心策略：按单位价值由大到小先装入背包，直到不能再装入物品为止。

设背包容量为 505050，现有 333 个物体：

物体 111： 体积为 101010、价值为 606060，单位价值为： 60/10=660/10=660/10=6

物体 222： 体积为 202020、价值为 100100100，单位价值为： 100/20=5100/20=5100/20=5

物体 333： 体积为 303030、价值为 120120120，单位价值为： 120/30=4120/30=4120/30=4

如果按照贪心策略，选择物体 111 和物体 222 装入背包，体积和为 303030，价值为和为 160160160。但是，如果选择物体 222 和 333，则价值为 220220220。

所以在 010101 背包问题下，不能使用贪心策略，其错误的原因在于； 每个物品要么选，要么不选，不能只选部分，因此就可能有剩余空间，从而减小背包的单位价值。

[2].动态规划

显然这是子集生成问题。

1). 状态函数：

f(i,j)f(i,j)f(i,j) 表示前 iii 个物品选择一些装入容量为 jjj 的背包，所能获得最大价值；

2).问题的答案：

ans=f(N,C)ans=f(N,C)ans=f(N,C)；

3).状态转移方程：

根据分步决策的分析方法，可得出：

f(i,j)=max⁡(f(i−1,j),p[i]+f(i−1,j−v[i]))(i>0)(j≥0)(j−v[i]≥0)f(i,j)=\max(f(i-1,j),p[i]+f(i-1,j-v[i]))(i>0)(j\geq0)(j-v[i]\geq0)f(i,j)=max(f(i−1,j),p[i]+f(i−1,j−v[i]))(i>0)(j≥0)(j−v[i]≥0)

4).边界分析：

f(0,j)=0   (j≥0)f(0,j)=0\ \ \ (j\geq0)f(0,j)=0   (j≥0) //000 个物品装入容量为 jjj 的背包，最大价值为 000；

f(i,0)=0   (i≥0)f(i,0)=0\ \ \ (i\geq0)f(i,0)=0   (i≥0) //iii 个物品装入容量为 000 的背包，最大价值为 000。

5).优化：

通过状态转移数组可知，前 iii 个物品的状态只与 i−1i-1i−1 层有关，故我们可以采用滚动数组优化，将二维降至一维。

f(j)f(j)f(j) 代表选择物品装入容量为 jjj 的背包时，能获得的最大价值。

ans=f(C)ans=f(C)ans=f(C)

f(j)=max⁡(f(j),f(j−v[i])+p[i])   (j−v[i]≥0)f(j)=\max(f(j),f(j-v[i])+p[i])\ \ \ (j-v[i]\geq0)f(j)=max(f(j),f(j−v[i])+p[i])   (j−v[i]≥0)

边界：f(j)=0   (1≤j≤C)f(j)=0\ \ \ (1\leq j \leq C)f(j)=0   (1≤j≤C)

这里为什么要倒着搜呢？

很简单的原因，假如我们正着搜，则会出现以下情况：

  1. f[j]f[j]f[j] 被 f[j−v[i]]+p[i]f[j-v[i]]+p[i]f[j−v[i]]+p[i] 更新。
  2. f[j+v[i]]f[j+v[i]]f[j+v[i]] 被 f[j]+p[i]f[j]+p[i]f[j]+p[i] 更新。

很明显，在同一阶段内(即同时处于第 iii 阶段)，相当于我们用 DP 更新了两次状态，即使用了两次物品，违背了题目要求，故只能使用倒序搜索。

(2).多重背包

有 NNN 种物品，每种物品只有 n[i]n[i]n[i] 个。第 iii 种物品的体积为 v[i]v[i]v[i]，价值为 p[i]p[i]p[i]。选一些物品装入一个容量为 CCC 的背包，使得背包内物品在总体积不超过 CCC 的前提下价值尽量大。

1). 状态函数：

f(j)f(j)f(j) 代表选择物品装入容量为 jjj 的背包时，能获得的最大价值。

2).问题的答案：

ans=f(C)ans=f(C)ans=f(C)

3).状态转移方程：

f[j]=max⁡(f[j],f[j−v[i]×l]+p[i]×l)   (j−v[i]≥0)(0≤l≤t)(t=min⁡(n[i],jv[i]))f[j]=\max(f[j],f[j-v[i]\times l]+p[i]\times l)\ \ \ (j-v[i]\geq 0)(0\leq l \leq t)(t=\min(n[i],\frac{j}{v[i]}))f[j]=max(f[j],f[j−v[i]×l]+p[i]×l)   (j−v[i]≥0)(0≤l≤t)(t=min(n[i],v[i]j​))

4).边界分析：

f(j)=0   (1≤j≤C)f(j)=0\ \ \ (1\leq j \leq C)f(j)=0   (1≤j≤C)

5).优化

多重背包有一种优化方式，能使它的时间复杂度降低一个层次。

这种优化方法通常称为二进制优化。

我们可以利用二进制拆分的方式，把 n[i]n[i]n[i] 个物品拆分成多个不同的组合，202^020,212^121,222^222…,2k2^k2k 为一组，将每一组看成一个整体，作为一个单独的物品。

然后多重背包就转换为 010101 背包了，直接用 010101 背包做就行了。

	return 0;
}

#include<stdio.h>
#include<string.h>
int n,v,m[5010],w[5010],s[5010],w1[50100],s1[50100],cnt;
int f[510];
int max(int a,int b)
{
	if(a>b)
		return a;
	return b;
}
int main()
{
	scanf("%d%d",&n,&v);
	for(int i=1;i<=n;i++)
		scanf("%d%d%d",&m[i],&w[i],&s[i]);
	for(int i=1;i<=n;i++)
	{
		for(int j=1;j<=m[i];j<<=1)
		{
			w1[++cnt]=j*w[i];
			s1[cnt]=j*s[i];
			m[i]-=j;
		}
		if(m[i])
		{
			w1[++cnt]=m[i]*w[i];
			s1[cnt]=m[i]*s[i];
		}
	}
	for(int i=1;i<=cnt;i++)
		for(int j=v;j>=w1[i];j--)
			f[j]=max(f[j],f[j-w1[i]]+s1[i]);
	printf("%d",f[v]);
	return 0;
}

(4).多费用背包

有 NNN 个物品，第 iii 个物品的体积为 vivivi，重量为 wiwiwi，价值为 pipipi。选一些物品装到一个最大容量为 CCC，最大承重量为 GGG 的背包，问如何选择装入背包的物品，使得装入背包的物品的总价值尽量大。

(9).背包问题总结

1).动态规划是解决最优性问题的有力武器，其的关键是状态函数和状态转移方程

状态函数的定义一般根据题目的问题，问什么设什么，且要充分包含题目描述中的各“变量”。状态转移方程的就是要决策达到当前状态的最优值，有那些选项，并从这些选项中决策出最优的选项。

2).动态规划状态函数的边界分析是基础

动态规划通过状态函数的逐步转移来计算目标状态的最优值的，但必须要有一个转移的起点，分析边界时一般根据状态函数中变量的意义来确定，或者根据填表法或记忆化搜索的过程来分析。

另外，边界一般可能的值是：000 ，∞\infty∞ 或 −∞-\infty−∞。

000 一般表示边界状态可行；

∞\infty∞ 一般表示计算最小值的时候边界状态不可行；

−∞-\infty−∞ 一般表示计算最大值的时候边界状态不可行。

5.物品选取

小沐同学确信所有问题都有个多项式时间算法，为了证明，他决定自己去当一次旅行商，在上路之前，小 XXX 需要挑选一些在路上使用的物品，但他只有一个能装体积为 mmm 的背包。显然，背包问题对小沐来说过于简单了，所以他希望你来帮他解决这个问题。

小沐可以选择的物品有 nnn 样，一共分为甲乙丙三类：

  1. 甲类物品的价值随着你分配给他的背包体积变化，它的价值与分配给它的体积满足函数关系式，v(x)=Ax2−Bxv(x) = Ax^2-Bxv(x)=Ax2−Bx，xxx 表示分配给该物品的体积，为非负整数，AAA，BBB 是每个甲类物品的两个参数。注意每个体积的甲类物品只有一个。
  2. 乙类物品的价值 AAA 和体积 BBB 都是固定的，但是每个乙类物品都有个参数 CCC，表示这个物品可供选择的个数。
  3. 丙类物品的价值 AAA 和体积 BBB 也是固定的，但是每个丙类物品可供选择的个数都是无限多个。

你最终的任务是确定小沐的背包最多能装有多大的价值上路。

1).状态函数

很明显这也是一个背包问题，这是一个混合背包问题。

容易可以看出，第 222 类物品属于多重背包，第 333 类物品属于完全背包。

第 111 类是一种新的背包类型，这时物品价值随分配给它的体积变化，属于泛化背包。

所以我们还是和以前一样的状态函数：

f(j)f(j)f(j) 代表选择物品装入容量为 jjj 的背包时，能获得的最大价值。

2).问题的答案

ans=max⁡(f(i))   (0≤i≤m)ans=\max(f(i))\ \ \ (0 \leq i \leq m)ans=max(f(i))   (0≤i≤m)

这里由于第 111 类的背包分配给的体积随时在变化，所以使得整个背包价值最大时的体积并不一定是 mmm，所以要重新遍历检索一遍。

3).状态转移方程

这要看物品的类型。

对于类型 111：f[j]=max⁡(f[j],f[j−k]+s[i].a×k2−s[i].b×k)f[j]=\max(f[j],f[j-k]+s[i].a\times k^2 -s[i].b\times k)f[j]=max(f[j],f[j−k]+s[i].a×k2−s[i].b×k)；

对于类型 222：f[j]=max⁡(f[j],f[j−k×s[i].b]+k×s[i].a)f[j]=\max(f[j],f[j-k\times s[i].b]+k\times s[i].a)f[j]=max(f[j],f[j−k×s[i].b]+k×s[i].a)；

对于类型 333：f[j]=max⁡(f[j],f[j−s[i].b]+s[i].a)f[j]=\max(f[j],f[j-s[i].b]+s[i].a)f[j]=max(f[j],f[j−s[i].b]+s[i].a)。

4).边界条件

f[0]=0f[0]=0f[0]=0

f[i]=−∞   (1≤i≤m)f[i]=-\infty\ \ \ (1 \leq i \leq m)f[i]=−∞   (1≤i≤m)

因为这里类型 111 物品的价值可能为负，所以要设为 −∞-\infty−∞。

5).代码
#include<cstdio>
#include<cstring>
#include<algorithm>
using namespace std;
int n,m;
struct thing
{
	int x;
	int a;
	int b;
	int c;
}s[110];
int f[2010];
int main()
{
	memset(f,-0x3f,sizeof(f));
	f[0]=0;
	scanf("%d%d",&n,&m);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&s[i].x);
		if(s[i].x==2)
			scanf("%d%d%d",&s[i].a,&s[i].b,&s[i].c);
		else
			scanf("%d%d",&s[i].a,&s[i].b);
	}
	for(int i=1;i<=n;i++)
	{
		if(s[i].x==1)
		{
			for(int j=m;j>=0;j--)
				for(int k=j;k>=0;k--)
					f[j]=max(f[j],f[j-k]+s[i].a*k*k-s[i].b*k);
		}
		else if(s[i].x==2)
		{
			for(int j=m;j>=s[i].b;j--)
				for(int k=0;k<=s[i].c&&k*s[i].b<=j;k++)
						f[j]=max(f[j],f[j-k*s[i].b]+k*s[i].a);
		}
		else
		{
			for(int j=s[i].b;j<=m;j++)
				f[j]=max(f[j],f[j-s[i].b]+s[i].a);
		}
	}
	int ans=0;
	for(int i=0;i<=m;i++)
		ans=max(ans,f[i]);
	printf("%d",ans);
	return 0;
}
