后缀数组(SA)

发表于 2020-01-18- 更新于 2026-09-20
3.1k- 14m
算法竞赛

后缀数组 (Suffix Array\text{Suffix Array}Suffix Array) 是一个十分厉害的数据结构，主要维护字符串后缀，并解决一些与 LCP\text{LCP}LCP (最长公共前缀) 的问题。

首先来了解一些基本概念：

子串

在字符串 sss 中，任意取 i≤ji\le ji≤j ，那么在 sss 中截取从 iii 到 jjj 的这一段即是 sss 的子串。

后缀

后缀即字符串中某个位置 iii 到字符串末尾的子串，定义 sss 的第 iii 个字符为第一个元素的后缀为 suff(i)\text{suff(i)}suff(i)。

后缀数组

把 sss 的每个后缀按照字典序排序，后缀数组 sa[i] 就表示排名为 iii 的后缀的起始位置下标。

另外一个辅助数组 rank[i] 代表起始位置下标为 iii 的后缀的排名。

两者可以互相映射。

基数排序

一个时间复杂度接近 O(log n)\text{O(log n)}O(log n) 的排序方法，比快排更优，基础是桶排序。

基数排序思路很简单，就是把数的每一位进行一遍桶排，最后即可得到答案。

例如如下数据：

数据 12 34 56 15 31 52
排名 1 4 6 2 3 5

具体是这样排的：

先按个位进行桶排序：

数据 31 12 52 34 15 56
个位数 1 2 2 4 5 6

再按十位对新得到的序列进行桶排序：

数据 12 15 31 34 52 56
十位数 1 1 3 3 5 5

代码：

#include<cstdio>
#include<cstring>
#include<cstdlib>
#include<cmath>
#include<algorithm>
#include<ctime>
#define INF 1e9
using namespace std;
const int maxn=2e5;
int n,a[maxn],b[maxn],t[11],maxx,p;
int getbit()//得到最大数的位数
{
	for(int i=1;i<=n;i++)
		maxx=max(maxx,a[i]);
	while(maxx)
	{
		maxx/=10;
		p++;
	}
	return p;
}
void radixsort()
{
	p=getbit();
	int radix=1;
	for(int i=1;i<=p;i++)
	{
		for(int j=0;j<=9;j++)
			t[j]=0;//初始化桶
		for(int j=1;j<=n;j++)
		{
			int k=(a[j]/radix)%10;
			t[k]++;//往桶里添加数
		}
		for(int j=1;j<=9;j++)
			t[j]=t[j-1]+t[j];//更新排名，计算比j小的数有多少个
		for(int j=n;j>=1;j--)
		{
			int k=(a[j]/radix)%10;
			b[t[k]]=a[j];//排答案
			t[k]--;
		}
		for(int j=1;j<=n;j++)
			a[j]=b[j];//复制
		radix*=10;//扩大10倍继续排下一位
	}
}
int main()
{
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
		scanf("%d",&a[i]);
	radixsort();
	for(int i=1;i<=n;i++)
		printf("%d ",a[i]);
	return 0;
}

接下来就是重点内容了。

后缀数组主要有两种求法：倍增和 DC3{DC3}DC3，其中倍增比较广泛使用，故以倍增为例进行讲解。

倍增 SA\text{SA}SA 算法

由于字符串长度小于 888，于是可以结束排序，得到 rank 数组，如下：

{
	for(int i=1;i<=m+1;i++)
		t[i]=0;//初始化
	for(int i=1;i<=n;i++)
		t[a[i]]++;//统计

}
bool check(int r[],int a,int b,int j)
{
	return r[a]==r[b]&&r[a+j]==r[b+j];
}
void get_SA(int a[],int b[])
{
	for(int i=1;i<=n;i++)
	{
		m=max(m,a[i]=s[i]);//赋值，求出最大数
		b[i]=i;//初始顺序
	}
	radixsort(a,b);
	for(int j=1;j<=n;j<<=1)//倍增长度
	{
		int p=0;
		for(int i=1;i<=j;i++)
			b[++p]=n-j+i;
		for(int i=1;i<=n;i++)
			if(sa[i]>j)
				b[++p]=sa[i]-j;
		radixsort(a,b);
		int *t=a;
		a=b;
		b=t;

			a[sa[i]]=check(b,sa[i],sa[i-1],j)?p:++p;
		if(p>=n)
			break;
		m=p;
	}
}

这是基数排序的代码。ttt 数组是排序的桶，aaa 数组是第一关键字，bbb 数组是第二关键字， mmm 是 aaa 数组的范围。

首先先将桶清空，然后将 aaa 数组扔进桶中排序，接着更新 ttt 数组，此时 ttt 数组代表小于等于 iii 的数有多少个，即 iii 的排名 +1{+1}+1。

最后倒序，将 bbb 从大到小(因为 bbb 的顺序是按照第二关键字的顺序来排的，第二关键字靠后的，在同一个第一关键字桶中同样靠后)取出，结合第一关键字 aaa 数组，−1-1−1 后得到排名，赋值即可。

接着交换 a,ba,ba,b 数组，因为生成新的第一关键字 aaa 数组时要用到旧的，正好此时 bbb 数组没用，就把此时的 aaa 放进 bbb 中。

很明显 a[sa[1]]=1a[sa[1]]=1a[sa[1]]=1，赋值即可，然后把 ppp 重新设为 111，开始求新的第一关键字。

从 2∼n2\sim n2∼n 遍历，此时需要 check 函数，如下所示：

结合 check 函数，因为 sa[i]{sa[i]}sa[i] 已经排好序了，所以直接按排名枚举，同时检查 b[sa[i]]{b[sa[i]]}b[sa[i]] 与 b[sa[i−1]]{b[sa[i-1]]}b[sa[i−1]] 是否相同，由于此时 bbb 数组保存的是之前的 aaa 数组，所以如果排名相同 p++p++p++，否则不变。

此时得到的 ppp 就是不同的字符串的个数，如果 p≥np\ge np≥n，那么周期长度的字符串在原串中不会重复出现，接下来的排序不会改变 rank 值，直接结束即可，否则令 m=pm=pm=p，改变范围。

最长公共前缀 LCP\text{LCP}LCP

定义一个新的数组 height[i]{height[i]}height[i]。

定义 height[i]=suff(sa[i−1]){height[i]=\text{suff}(sa[i-1])}height[i]=suff(sa[i−1]) 和 suff(sa[i])\text{suff}(sa[i])suff(sa[i]) 的最长公共前缀，也就是排名相邻的两个后缀的最长公共前缀，那么有如下性质：

对于任意 rank[j]<rank[k]{rank[j]<rank[k]}rank[j]<rank[k]，suff(j)\text{suff}(j)suff(j) 和 suff(k)\text{suff}(k)suff(k) 的最长公共前缀为：

min⁡(height[rank[j]+1],height[rank[j]+2],⋅⋅⋅,height[rank[k]]) \min(height[rank[j]+1],height[rank[j]+2],···,height[rank[k]]) min(height[rank[j]+1],height[rank[j]+2],⋅⋅⋅,height[rank[k]])

那么如何快速求出 height{height}height 数组呢？

令 h[i]=height[rank[i]]{h[i]=height[rank[i]]}h[i]=height[rank[i]]，也就是 suff(i)\text{suff}(i)suff(i) 和它前一个后缀的最长公共前缀，其中 h{h}h 数组满足以下性质：

h[i]≥h[i−1]−1 h[i] \ge h[i-1]-1 h[i]≥h[i−1]−1

具体实现：

void get_high(int sa[])
{
	for(int i=1;i<=n;i++)
		rank[sa[i]]=i;//反推rank
	int j=0;
	for(int i=1;i<=n;i++)
	{
		if(j)
			j--;
		while(i+j<=n&&sa[rank[i]-1]+j<=n&&s[i+j]==s[sa[rank[i]-1]+j])
			j++;
		height[rank[i]]=j;
	}
}

首先通过得到的 sa{sa}sa 数组反推 rank{rank}rank 数组，接着看看循环内：

if(j)
	j--;

这个其实是上面性质 h[i]≥h[i−1]−1{h[i]} \ge {h[i-1]-1}h[i]≥h[i−1]−1 的化用，因为 jjj 其实保存的就是 h[i−1]h[i-1]h[i−1]，即 height[rank[i−1]]height[rank[i-1]]height[rank[i−1]]。

接着就是粗暴的按照每位依次对比，如果相同长度加 111，然后赋值即可。

综上，基本的后缀数组就讲完了，后缀数组可以完成很多有用的操作，是一个很厉害的数据结构。

Luogu模板 后缀排序(SA)：

#include<cstdio>
#include<cstring>
#include<cstdlib>
#include<cmath>
#include<algorithm>
#include<ctime>
#define INF 1e9
using namespace std;
const int maxn=2e6;
int n,m,k;
char s[maxn];
int sa[maxn],t[maxn];
int a[maxn],b[maxn];
void radixsort(int a[],int b[])//基数排序
{
	for(int i=1;i<=m+1;i++)
		t[i]=0;//初始化
	for(int i=1;i<=n;i++)
		t[a[i]]++;//统计
	for(int i=1;i<=m;i++)
		t[i]+=t[i-1];//更新
	for(int i=n;i>=1;i--)
		sa[t[a[b[i]]]--]=b[i];
}
bool check(int r[],int a,int b,int j)
{
	return r[a]==r[b]&&r[a+j]==r[b+j];
}
void get_SA(int a[],int b[])
{
	for(int i=1;i<=n;i++)
	{
		m=max(m,a[i]=s[i]);//赋值，求出最大数
		b[i]=i;//初始顺序
	}
	radixsort(a,b);
	for(int j=1;j<=n;j<<=1)//倍增长度
	{
		int p=0;
		for(int i=1;i<=j;i++)
			b[++p]=n-j+i;
		for(int i=1;i<=n;i++)
			if(sa[i]>j)
				b[++p]=sa[i]-j;
		radixsort(a,b);
		int *t=a;
		a=b;
		b=t;
		a[sa[1]]=p=1;
		for(int i=2;i<=n;i++)
			a[sa[i]]=check(b,sa[i],sa[i-1],j)?p:++p;
		if(p>=n)
			break;
		m=p;
	}
}
int main()
{
	scanf("%s",s+1);
	n=strlen(s+1);
	get_SA(a,b);
	for(int i=1;i<=n;i++)
		printf("%d ",sa[i]);
	return 0;
}
